## 🔬 Research

### 🚁 Image-Based Localization for GPS-Denied Drone Navigation
> Python · OpenCV · ORB · SIFT · DISK · RANSAC · Bennett University · Jun – Aug 2026

7-week faculty-guided study: designed a VisDrone benchmark (10 images, 4 stress scenarios) and compared classical and learned-feature pipelines. SIFT gave 2.6× more geometrically-consistent matches than ORB under viewpoint change, while DISK held its full keypoint budget in low-texture scenes at ~400× the CPU cost. Implemented 6-DOF pose recovery (essential matrix + RANSAC) and tuned the deployed ORB configuration for ≈11× lower latency with no loss in verified matches.
