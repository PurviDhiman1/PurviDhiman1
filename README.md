### 🔥 Featured Projects

#### 🤖 [QueryDesk — AI Customer Support RAG Agent](https://github.com/PurviDhiman1/QueryDesk)
An AI support assistant powered by **Retrieval Augmented Generation**: retrieves answers from a knowledge base via ChromaDB + HuggingFace embeddings, then generates grounded, cited responses with a Groq LLM. Includes conversational memory and a Streamlit chat UI.

**🔗 [Live Demo](https://querydesk-ai.streamlit.app/)**

`Python` `LangChain` `Groq` `ChromaDB` `Streamlit`

---

#### 🌍 [ResQAI](https://github.com/PurviDhiman1/resqai)
AI-powered disaster response platform enabling real-time reporting, emergency guidance, duplicate-report detection, and smarter response coordination with maps integration.

`JavaScript` `AI` `Maps API`

---

#### 🤝 [Peer Study Matchmaker](https://github.com/PurviDhiman1/Peer-Study-Matchmaker) ⭐
Matches students with compatible study partners using an ML-based system that scores subjects, study style, and availability. Next.js frontend + Flask backend.

`TypeScript` `Next.js` `Flask` `ML`

#### 🎨 [Gully Lab Redesign](https://github.com/PurviDhiman1/gullylab-redesign)

`JavaScript` `UI/UX`
